A modern and interactive Productivity Dashboard built using HTML, CSS, JavaScript.
This dashboard helps users manage their daily productivity with features like task management, daily planning, motivational quotes, pomodoro timer, weather updates, and multiple theme modes — all inside a clean and responsive UI.

Features

✅ Todo Manager -
Add tasks with details
Mark important tasks
Remove completed tasks
Tasks stored using localStorage

📅 Daily Planner -
Hourly planner for the entire day
Auto-save functionality
Persistent planner data using localStorage

💡 Motivational Quotes -
Random quote generator using API
Dynamic author rendering

⏳ Pomodoro Timer -
25-minute work session
5-minute break session
Start / Pause / Reset controls

🌦 Weather Widget -
Real-time weather data
Temperature, humidity, precipitation, and wind speed
Live date & time display

🎨 Dynamic Themes -
Multiple UI themes
Smooth theme switching
